# Status Checks

How to read this page

Every lane segment in a real Argoverse 2 log is scored by three independent checks and combined into an unweighted risk vote (0–3). Anything with risk ≥ 1 goes to REVIEW.

Hover a table row to find it on the map; hover a lane on the map to find its row. Switch regions above — each one is pulled, scored, and loaded into S3 by the same ETL pipeline: Extract (public AV2 bucket) → Transform (the three checks below) → Load (S3, raw log + this review queue).

G  Geometry — LiDAR residual vs. candidate lane-marking points T  Topology — dangling successor/predecessor references S  Semantic — declared-neighbor plausibility
